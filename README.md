# CodeSim Lab

Abre CodeSim-Lab.html con doble clic. El laboratorio, el modo docente y la evaluación funcionan sin internet. En el primer acceso docente de la copia de GitHub, escribe y confirma la contraseña que quieras usar en ese navegador. En las siguientes entradas basta con escribirla una vez.

El estudiante se identifica con nombre y correo, y elige Material de estudio o Presentar evaluación. La evaluación tiene 25 misiones, 90 minutos y hasta tres intentos por misión. Al acertar o al tercer fallo, Aceptar abre la siguiente misión.

Al entregar el examen, el archivo guarda el resultado en el navegador. El envío a Google Sheets se intenta al volver internet o al abrir otra vez este mismo archivo en el mismo navegador. El aviso «Evaluación enviada a Google Sheets» aparece cuando Google confirma la recepción.

Para activar los envíos desde este archivo, abre Extensiones → Apps Script en la hoja y reemplaza el contenido de Código.gs por el Code.gs incluido en esta carpeta. Guarda el proyecto. En Implementar → Gestionar implementaciones → Editar elige Nueva versión y pulsa Implementar. Conserva «Ejecutar como: Yo», «Quién tiene acceso: Cualquier persona» y las propiedades del script ya configuradas. Esto conserva el enlace que utiliza el HTML y mantiene privada la hoja.

La hoja identifica estos resultados como provenientes del HTML. La nota se calcula en el navegador y el archivo por sí solo no verifica la identidad del estudiante.
